# T6-week11
Aplikasi desktop CRUD Post Manager menggunakan Python PySide6 dan REST API.
Aplikasi menerapkan multi-threading agar UI tetap responsif saat melakukan request API.

## Fitur
- GET semua post
- Detail post
- Tambah post
- Edit post
- Hapus post
- Multi-threading
- Error handling
- Validasi slug unik
